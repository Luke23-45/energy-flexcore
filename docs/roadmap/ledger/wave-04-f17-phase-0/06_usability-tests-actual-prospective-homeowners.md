# W4.06 — Usability tests with actual prospective homeowners, not just engineers

Workstream: companion-repo work (separate identity/database — NOT FlexCore control-plane work)

- **Objective:** Conduct usability tests with actual prospective homeowners (not just engineers), per design §14 F-17 Phase 0 and the foundations.md F-17 validation rule, to find out whether they need an estimate, a configuration comparison, or help navigating installation.
- **Design trace:** Design §14 F-17 Phase 0; foundations.md F-17 validation rule
- **Inputs / prerequisites:** Design §14 F-17 Phase 0; foundations.md §8 items 3–4; W4.04 prototype.
- **Steps:**
  1. Recruit actual prospective homeowners who are considering solar (not engineers, not the project team) and run the prototype with them.
  2. Record what each participant needed: an estimate, a configuration comparison, or help navigating the installation process (foundations.md §8 item 4).
  3. Record where participants struggled, misunderstood a result, or needed information the prototype did not provide.
  4. Record the usability verdict: what homeowners needed, where they struggled, and what must change before Phase 1 (the accuracy/usefulness verdict on the regional data belongs to W4.05, not here).
- **Deliverable / output:** A usability-test record: participants (prospective homeowners), what each needed, where they struggled, and the usability verdict.
- **Acceptance criteria / exit check:**
  - [ ] Participants are actual prospective homeowners considering solar, not engineers.
  - [ ] Each participant need is recorded as estimate, configuration comparison, installation navigation, or another stated need.
  - [ ] Struggle points and missing information are recorded.
  - [ ] The record gives a usability verdict (needs met, struggle points, changes required before Phase 1).
- **Owner role:** Product
- **Dependencies:** W4.04, W4.05
- **Verification method:** Usability record inspected: participant profile, needs, struggle points and verdict all present.
- **Risks / failure modes:** Testing only with engineers and concluding homeowners understand the output. Mitigation: participants must be prospective homeowners.
