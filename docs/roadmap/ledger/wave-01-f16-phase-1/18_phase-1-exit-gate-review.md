# W1.18 — Phase 1 exit-gate review

Workstream: FlexCore control-plane work

- **Objective:** Hold the F-16 Phase 1 exit-gate review against the design §14 exit gate: a real assessor/facility operator can create, correct, review and export a defensible evidence package; every output has source and limitation records; no automatic dispatch qualification and no claims of formal ASHRAE conformance.
- **Design trace:** Design §14 F-16 Phase 1 exit gate
- **Inputs / prerequisites:** W1.01–W1.17, W1.19 and W1.20 outputs; design §14 F-16 Phase 1.
- **Steps:**
  1. Check the exit gate with a real assessor/facility operator (not only engineers): create, correct, review and export a defensible evidence package end to end.
  2. Verify every output in the package has source and limitation records (per W1.07 provenance and W1.10/W1.17 disclosure), and verify the readiness report (W1.19) and the F-16 tariff pack (W1.20) are evidenced.
  3. Confirm no automatic dispatch qualification exists in Phase 1 and no claim of formal ASHRAE conformance is made anywhere in Phase 1 outputs.
  4. List any exit-gate item not met with its owner and follow-up, and hand over to Wave 2 only on the stated conditions.
- **Deliverable / output:** A Phase 1 exit-gate review record with a per-item verdict, the operator walkthrough evidence, and the Wave 2 handover conditions.
- **Acceptance criteria / exit check:**
  - [ ] The real assessor/operator walkthrough (create, correct, review, export) is evidenced.
  - [ ] Every output checked has source and limitation records.
  - [ ] The readiness report (W1.19) and the F-16 tariff pack (W1.20) are evidenced.
  - [ ] The record confirms no automatic dispatch qualification and no formal ASHRAE conformance claim in Phase 1.
  - [ ] Any unmet item has a named owner and follow-up; Wave 2 start conditions are stated.
- **Owner role:** Product + power systems
- **Dependencies:** W1.01, W1.02, W1.03, W1.04, W1.05, W1.06, W1.07, W1.08, W1.09, W1.10, W1.11, W1.12, W1.13, W1.14, W1.15, W1.16, W1.17, W1.19, W1.20
- **Verification method:** Exit-gate checklist against design §14 F-16 Phase 1; walkthrough evidence inspected.
- **Risks / failure modes:** Declaring the gate met on an engineer-only demo. Mitigation: a real assessor/facility operator must perform the walkthrough.
