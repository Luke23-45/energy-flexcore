## 1. What the adapter is (and is not)

| Aspect | Recorded state |
|---|---|
| Role | AggregatorServer (the CSIP aggregator role [S-1][S-3]); DER devices connect to it as TLS clients |
| Resource tree | EndDevice/FunctionSetAssignments/DERProgram/DefaultDERControl/DERControlList/Response/Pricing/LogEvent model types (record 02 §2) — spellings UNVERIFIED against the standard text |
| Direction | GET reads plus bounded device POSTs to Response/LogEvent collections ONLY; a write anywhere else is refused (`NotAllowed`) — not a command path |
| Authority | One-variant `AuthorityDeclaration::SupervisoryRelayOnly`; dispatch authority is not expressible in the type (record 01 §2) |

## 3. Security (enrollment, credentials, certificates)

| Topic | Design position (record 03 governs) |
|---|---|
| mTLS | Client certificates STRUCTURALLY required — `MtlsRequirements` has no field that could disable them; an empty trust-anchor set is a construction error; revocation checking defaults fail-closed |
| Trust anchors | The platform stores anchor LABELS composed at deployment — never key material |
| Enrollment | Operator-mediated: a device presents its certificate, the deployment approves the EndDevice resource; never an unattended write into the tree |
| SFDI / LFDI | Shape-only validated value types in the adapter; the exact derivation (hash input, bit length, shortening rule) is record 03 §3's UNVERIFIED check — resolved by humans before any security-bearing implementation |
| Secrets custody | Phase 13 secrets surface; the adapter reads secret REFERENCES — `secret.read` stays in the never-granted set |
| Certificate lifecycle | Root/device-CA standup, issuance, rotation, revocation are HUMAN PKI operations (record 03 §4 — none exists; NOT-STARTED) |

## 4. Operations (budgets, observability, failure modes)

| Topic | Design position |
|---|---|
| Collection caps | Declared `ServerLimits` per collection; oldest dropped when a cap is exceeded — unbounded device-facing lists are a denial-of-service surface, not a feature |
| Paging | Explicit limit/offset with exact `all`/`results` meta recount — a design simplification; the standard's wire parameter names are UNVERIFIED |
| Scheduling windows | `DerControlWindow` half-open `active_at` with declared randomization (semantics UNVERIFIED) |
| Connection states | CLOSED / CONNECTING / CONNECTED / DEGRADED / UNREACHABLE via the common `ProtocolConnection` port — the P11 observability vocabulary consumes these names (never redefines them) |
| Failure modes | Undeclared path → 404 indistinguishable from a missing resource; write outside the declared collections → `NotAllowed`; out-of-scope request → the scope gate's fail-closed refusal; unwired transport → the named seam refusal |
| External controls | Every DERControl maps to a PROPOSED lifecycle candidate (const entry state); gate-skipping transitions are refused by the frozen table |

## 5. Honest boundary and certification pointer

No server exists, no device was enrolled, no DERControl was received, no
message was exchanged. The written-unrun CSIP use-case suite (record 04)
is evidence structure for the human-gated lab conversation described in
the conformance evidence plan (records 101 — phase-14 record range
101–104); the lab's own procedures govern, and a lab pass is a test
outcome, never a guarantee. FlexCore is not certified.
